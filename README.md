# Liste des neuroscientifiques

## Présentation du projet

Ce dépôt GitHub contient une liste de neuroscientifiques répertoriés sur Wikipédia.

## Source des données

Les informations proviennent de la page Wikipédia suivante :

https://en.wikipedia.org/wiki/List_of_neuroscientists

## Contenu du dépôt

Le fichier `neuroscientifiques.csv` contient les noms des neuroscientifiques et les informations associées, telles que leurs dates de naissance et de décès, leur nationalité et leurs distinctions.
